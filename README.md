# PDFNest

A modern, fast, privacy-focused PDF toolkit built with **Next.js 16**, **TypeScript**, and **Tailwind CSS**.

PDFNest allows users to work with PDF files directly in the browser without uploading them to a server whenever possible.

---

## Features

### Current

- Merge PDF
- Multiple File Upload
- Drag & Drop Upload
- Drag to Reorder Files
- Remove Individual Files
- Clear All Files
- Browser-Based Processing
- Responsive UI
- Toast Notifications

## Running Locally

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```
